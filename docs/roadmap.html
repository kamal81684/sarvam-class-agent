Architecture

How the pieces connect

The browser only talks to the Express backend; the backend is the only thing that holds the Sarvam key.

Teacher Studio

Topic to lesson in 6 steps

Each yellow step waits for the teacher: approve, or reject with feedback (up to 3 times). Times are measured on a real run.

Outline

Topic + notes become 5-8 sections with key points.

~9sreview

Slides

One interactive 1280×720 HTML slide per section, all built in parallel.

~35sreview

Discussion

Dr. Smith, Alex and Maya talk it through. Teacher can join or pass.

~2s/round

Analyse

AI flags slides the discussion showed were confusing.

~1spick

Improve

Picked slides are rewritten using the discussion.

~10s

Narrate

Teacher script per slide: each step highlights an element while the voice plays.

~8s
Student · Ask Doubt

Three ways to ask, one answer

The answer knows which slide the student is on and replies in the language they asked in, then reads it aloud.

Player · Narration

Why narration starts instantly

Each voice clip takes ~2.5s to make. The player fetches every step of the current and next slide at the same time, and the backend keeps clips on disk.

6 clips, one by one
~15s
6 clips in parallel
3.1s
Replay from disk cache
~1ms

Slides render on a fixed 1280×720 canvas that is scaled to fit, so nothing is cut off; the narrated element glows yellow while it is being explained.

Backend API

Endpoints at a glance

MethodPathWhat it does
POST/api/sessionsCreate lesson, generate outline
POST/api/sessions/:id/outlineApprove → slides, or reject with feedback
POST/api/sessions/:id/contentApprove slides → discussion
POST/api/sessions/:id/discussOne discussion round

POST/api/sttVoice → text + language
